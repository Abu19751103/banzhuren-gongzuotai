# 班主任工作台 · 班级管理中枢

一个给班主任用的单页应用：学生档案、考勤、奖惩积分、座位值日、成绩分析、家校沟通、工作留痕，全部在一个界面里完成。

**纯静态页面，没有任何后端**。数据存在浏览器 localStorage 里，不上传服务器，也不需要登录。

## 功能

| 模块 | 内容 |
| --- | --- |
| 仪表盘 | 今日课表、待办清单、考试倒计时、出勤率趋势、班级动态、积分预警 |
| 学生档案 | 花名册、家长联系方式、宿舍分组、座位、标签；支持**拼音首字母检索**（输入 `zs` 找到张三） |
| 座位表 | 6×7 可视化座位，点击两个座位互换，支持随机排座 / 按学号排列 |
| 分组与值日 | 学习小组概览（人数、均分、积分）、值日轮值表自动生成、岗位分工 |
| 考勤登记 | 逐人标记正常 / 请假 / 迟到 / 缺勤 / 早退，本月汇总与关注名单 |
| 奖惩积分 | 表扬、违纪、谈心、竞赛四类登记，积分榜、红花榜、阈值预警 |
| 班费事务 | 收支流水、余额、缴费状态、公示 |
| 成绩分析 | 新建考试 → 录入成绩（失焦自动保存）→ 学科统计、排名、分层建议、趋势图、学业预警 |
| 课表与作业 | 周课表在线编辑、作业提交率/批改率跟进、班会模板库一键写入留痕 |
| 通知发布 | 发布通知并逐人勾选已读回执，已读率可视化 |
| 家校沟通 | 通话 / 面谈 / 会议记录，按学生归档成时间线 |
| 工作留痕 | 班会、安全教育、家访记录归档，支持 CSV 导出与打印（可另存 PDF） |
| 数据备份 | 导出 / 导入 JSON，换设备迁移；可清空演示数据从零开始 |

## 使用

打开网页即用。首次打开内置了一份 **42 人的演示班级数据**（虚构），方便直接看到各模块效果。

换成自己班的数据，两种方式：

1. **从 Excel 导入**：在学生档案页点「从 Excel 导入」，在 Excel 里选中含表头的区域复制粘贴即可。识别列：姓名、学号、性别、分组、家长、电话。
2. **清空重录**：数据备份页点「清空全部数据」，然后逐个新增。

> 建议先把演示数据导出一份 JSON 作为格式参考。

## 数据安全

- 所有数据只存在当前浏览器的 localStorage（同一浏览器、同一设备）。
- 清除浏览器数据、换浏览器、换设备都会导致数据看不到 **不等于丢失** —— 但无法自动同步，请定期用「导出 JSON」备份。
- 手机和电脑之间迁移：电脑导出 JSON → 发到手机 → 手机打开网页 → 导入 JSON。

## 部署

纯静态，无构建步骤：

```bash
# 本地预览
python -m http.server 8080
# 打开 http://localhost:8080
```

GitHub Pages：仓库 Settings → Pages → Source 选 `main` 分支根目录 → 保存，稍等一分钟即可访问 `https://<用户名>.github.io/banzhuren-gongzuotai/`。

## 目录

```
index.html          页面骨架
assets/style.css    样式（含打印样式、移动端适配）
assets/data.js      数据层：localStorage、演示种子数据、拼音首字母表
assets/charts.js    无依赖 SVG 折线图 / 柱状图 / 环形图
assets/app.js       13 个视图的渲染与交互
```

无第三方依赖，不加载任何 CDN 资源，断网也能用。
